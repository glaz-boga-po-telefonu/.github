## Как устроен запрос

Откройте Глаз Бога бот в Телеграм, перейдите к поиску по телефону и введите номер полностью, с кодом страны. Сверьте цифры перед отправкой. Если ответ содержит несколько записей, разделяйте их по датам и связанным аккаунтам. Один телефон мог перейти другому человеку; старое имя в контактной книге не устанавливает текущего владельца.

## Что может быть в ответе

Совпавшая запись иногда содержит имя, контактную метку, связанный Telegram ID, ник или упоминание сервиса, где номер использовался. Конкретные поля определяются доступными записями. Связь с аккаунтом из прошлого периода не говорит, что человек использует номер сегодня. Когда даты нет, вывод об актуальности особенно ненадёжен. Если найдены разные имена, это может отражать смену владельца или ошибки в старых источниках.
